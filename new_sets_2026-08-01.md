## CORRECTION (added post-run) — JP Pokemon MEGA sets missed

The original Pokemon section below relied solely on pokedata.io's `/api/sets` feed, which was
**stale for Japanese sets** at probe time — its newest entry was 2026-05-22 and it contained
zero hits for the two newest JP MEGA expansions (verified: 0 occurrences of "Emeralda"/"Abyss"/
`m5`/`m6` in the raw feed). Cross-checking a JP release calendar surfaced them:

- `m6` · "Storm Emeralda" (Mega Rayquaza ex, JP MEGA set 6) · Released **2026-07-31** · **NOT in catalog**
- `m5` · "Abyss Eye" (Mega Darkrai ex, JP MEGA set 5) · Released **2026-05-22** · **NOT in catalog**

Newest JP MEGA set actually in catalog is `m4` "Ninja Spinner" (also present: `m1L` Mega Brave,
`M2` Inferno X, `M2a` Mega Dream, `M3` Nihil Zero). So both `m5` and `m6` are a real gap.

**Process fix:** pokedata lags on JP additions, so future runs must cross-check a JP release
calendar (PokeGuardian / PokeBeach) for Pokemon JP — the same web-calendar step already used
for the non-Pokemon games — rather than trusting the pokedata feed alone.

Ingest note: `pokedata_sync.py --only m6` depends on pokedata carrying the set; since the feed
doesn't list `m5`/`m6` yet, that path won't pull them until pokedata updates. Either wait for
pokedata to add them, or source the singles another way.
