### Feedback for the skill file

Four probe-method findings this run, each of which produced a wrong verdict
on first pass and was only caught by a second route:

1. **Pokemon EN ids are lowercase** (`en-me05-006`, `en-SVP-030` is the
   exception, not the rule). `id=like.en-ME05-*` returned **0** for a set with
   120 rows. Use `ilike` for every id-prefix probe, or probe `set_code=eq.`
   alongside.
2. **One Piece starter-deck ids are hyphenated** (`op-st-31-*`, not
   `op-st31-*`). Probe both shapes.
3. **`set_name ilike` false-positives on near-names** — `*Magnificent*` hit
   MAMA (Magnificent Mavens) for MAMO; `*Celebration*` hit `cel25` for the
   30th Celebration. Always confirm a name hit with `set_code` before calling
   it "already in catalog."
4. **PostgREST caps pages at 1,000 rows silently** — `limit=5000` returns
   1,000 with no error. Any "distinct set list" must paginate with `offset`
   (or use `Prefer: count=exact` and compare).

And two coverage changes worth making in the task file itself:

- **The pokedata feed is not a reliable Pokemon recency source** — it missed
  a worldwide anniversary launch. Add a Pokemon web cross-check to step 4b
  (pokemon.com's monthly "every product release" post + Bulbapedia/PokeBeach
  for JP) rather than treating pokedata as authoritative.
- **Add Lorcana to step 4b** now that `game_type=lorcana` exists in the
  catalog — its first post-import set was missed for 7 weeks.
